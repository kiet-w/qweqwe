# RTK + Code Review Graph Workflow

Thu muc nay gom cac tai lieu ve cach toi da lam viec trong project nay khi:

- clone giao dien vao Next.js
- dung `rtk` de doc file, chay test, lint, build
- dung code review graph de lay context va review thay doi
- tach UI theo layer dung logic
- them i18n vao App Router
