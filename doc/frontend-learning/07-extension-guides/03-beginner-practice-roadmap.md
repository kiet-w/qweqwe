## Dinh nghia "da hieu"

Ban co the xem la da hieu khi ban tra loi duoc:

- tai sao page khong nen chua het UI
- tai sao sidebar nam o widget ma shell nam o layout
- tai sao `ROUTES` va dictionary giam bug
- tai sao `shared/ui` khong nen biet route
- tai sao TypeScript strict la co loi cho nguoi moi
